# Positive Action for Parents

A three-session series for parents and caregivers on chronic absenteeism, presented by NJ4S Bergen Hub. Each session is a touchscreen HTML presentation, and each one builds on the one before.

| # | Session | Units | Slides |
|---|---------|-------|--------|
| 01 | [Understanding chronic absenteeism](session-1-understanding-chronic-absenteeism.html) | Self-concept · Our bodies and minds | 16 |
| 02 | [Strategies to improve attendance](session-2-strategies-to-improve-attendance.html) | Managing ourselves · Treating others well · Telling ourselves the truth | 15 |
| 03 | [Overcoming barriers to attendance](session-3-overcoming-barriers-to-attendance.html) | Improving ourselves continually | 16 |

Start at [`index.html`](index.html), the series menu.

## Presenting

- Open a session and press **F** for full screen on the touchscreen.
- Move between slides by swiping up or down, scrolling, or using the arrow keys.
- The **⋯** menu has speaker notes (**N**), a slide overview (**G**) and calm motion (**M**), which turns the animation off.
- When the decks run from the website, the session dots on each cover link to the other sessions.

## Offline

Each session is a single self-contained file with its fonts, logo and QR codes inside. Download it and it runs in any browser without internet.
